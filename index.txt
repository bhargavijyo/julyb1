//CSS display Properties : 
    used to show how an html element is displayed and how

        selector{

        }

        normally takes the full available width 
        block elements :<div>,<p>,<h1>,<section>...etc

                            It takes only required width by it's content 
                            inline elements -- <span>,<a>,<strong>,<em>
                            Box1 Box2 Box3

    3.display : inline-block; -- combination of inline + block 
                                stays in the same line like inline 
                                allows width and height like block 

    4.display: none; -- completely removes the element from the page layout 
                        The element not visible and it doesn't occupy any space.

                        column/row only

//FUNCTIONS -- 
                A function is a reusable block of code designed to perform a specific task.
                syntax:  function fn_name(){
                    //code
                }
                fn_name();

                1.Named Function => It is a function that has a specific name . we can call it using that name.
                            function fn_name(parameter1,..paremetern){
                                //code
                            }
                            fn_name(parameter1,..paremetern);
                2.Anonymous function => An anonymous function is function without name.
                                        It is usually assigned to a variable or passed as an arguments to another function 
                                        let a =function (parameters...){

                                        }
                3.Arrow Function => An arrow function is a shorter syntax for writing functions . 
                                    it was introduced in ES6(Ecmascript -- it is used to give advanced js features)
                                    let add = (a,b)=>{
                                        return a+b;
                                    };

                                    one parameter => let d = num => num*5;
                
                4.Callback function => it is a function that is passed as an argument/parameter to another function and 
                                        execute later by that function.
                                        function greet(name, callback){
                                            console.log("Hello", name);
                                            callback();
                                        }
                                        function msg(){
                                            console.log("Welcome to the JavaScript");
                                        }
                                        greet("JASIM", msg);//msg is callback function

                5.HOF(higher-order function) => It is a function that does at least one of these:
                                                1.takes another function as an argument
                                                2.returns the another function

                6.Currying function => Currying means converting a function that accepts multiple 
                                        arguments/parameters into a sequence of functions,
                                        where each function takes one arguement.
