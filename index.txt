//Task-2 
selectors -- A css selector used to select html elements so that we can apply styles to them
1.Element selector --  It selects all html elements with the same tag name (h1, p, button)
2.class selector -- Class selector is used to style one or more html elements(.)
3.id selector -- Id selector styles  only one unique html element and id should be used only once on a page (#)
4.universal selector -- Selects every html element on the web page(*)
5.group selector --  This will used to apply same style to multiple or different elements

//Box Modeling -- In this every Html element is treated as box and 
it determines how much space each element occupies on web page.
1.content -- Actual data inside the tags like text,img,buttons etc.
2.padding -- It is the space between the content and border.
3.border -- Is the line surrounding padding and content.
4.margin --  iSs the space outside the border.

//CSS positions -- used to control positon of an element on web page(how it placed like that)
1.position:static;  (default )
2.relative  -- original place(u can move it using top, left, right)
3.absolute -- the element removed from original position 
                absolute can search the non-static parent, once it reach the non-static parent it will
                act as the same as relative .
4.fixed -- Fixed place no change
5.sticky -- using top:0; once it reach top it will act as same fixed
