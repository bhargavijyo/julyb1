selectors -- A css selector used to select html elements so that we can apply styles to them
1.Element selector --  It selects all html elements with the same tag name (h1, p, button)
2.class selector -- Class selector is used to style one or more html elements(.)
3.id selector -- Id selector styles  only one unique html element and id should be used only once on a page (#)
4.universal selector -- Selects every html element on the web page(*)
5.group selector --  This will used to apply same style to multiple or different elements

//CSS display Properties : 
    used to show how an html element is displayed and how
    it behaves in the layout 
    syntax:
        selector{
            display : value;
        }
    1.display:block ;-- 
        It contains block-level element starts on a new line and
        normally takes the full available width 
        block elements :<div>,<p>,<h1>,<section>...etc
    
    2. display : inline; --Inline element does not start on new line 
                            It takes only required width by it's content 
                            inline elements -- <span>,<a>,<strong>,<em>
                            Box1 Box2 Box3

    3.display : inline-block; -- combination of inline + block 
                                stays in the same line like inline 
                                allows width and height like block 

    4.display: none; -- completely removes the element from the page layout 
                        The element not visible and it doesn't occupy any space.
    
    5.display : flex; -- It used to create a flexbox layout,
                        that makes easy to align, distribute ,size elements inside container. 

                        It is one-dim layout 
                        column/row only 
                        best small components
                        ex:Navbar,cards

                        It's useful for arranging elements in a row or column
                        display : flex;
                        flex-direction : row, row-reverse, col,col-reverse;
                        justify-content//align-content : center,top, end, space-around;
                        align-items : start,top,end,center;
                        gap: it can be set by user (10px,20px;)
                        flex-wrap: nowrap, wrap,wrap-reverse;(Allows items to move to the next line.)
                        flex on item: flex,1,2,3
                        order: we can change the visual order.

   6.grid -- 2d layout 
            row and column 
            it is best for full page creation 
            ex:full page, section
